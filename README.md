# Game Theory Projects

University projects for the **Game Theory** course at Sharif University of Technology.

### Projects

* **Strategic Endurance under Uncertainty (SEE)**
  A strategic decision-making game involving incomplete information, signaling, and reinforcement learning.

* **Approval-Based Committee Voting**
  An exploration and implementation of approval-based voting rules and the existence of the core.

More details and implementations can be found in each project's directory.
